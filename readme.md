Personal Website – Subki

Ini adalah project website pribadi sederhana yang dibangun menggunakan **HTML**, **CSS**, dan **JavaScript**. Tujuannya adalah sebagai media latihan sekaligus portofolio online untuk menampilkan profil, lokasi kantor, dan form interaktif kepada pengunjung.

Fitur
- 🔹 Responsive Layout – Desain mobile-friendly yang menyesuaikan berbagai ukuran layar.
- 🔹 Navbar Interaktif – Navigasi sederhana dengan struktur yang bersih dan terorganisir.
- 🔹 Welcome Section – Informasi pembuka dengan placeholder banner.
- 🔹 Headquarter Section – Menampilkan lokasi kantor dalam bentuk circle layout.
- 🔹 Message Us Form** – Form pengiriman pesan lengkap dengan validasi input.
- 🔹 Clean UI/UX – Menggunakan font *Poppins*, warna modern, dan struktur intuitif.

Teknologi yang Digunakan

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Google Fonts (Poppins)**
